
# 🗳️ Пайплайн подсчёта голосов для танцевального конкурса

Автоматическая обработка комментариев, извлечение пар и подсчёт результатов с возможностью ручной корректировки.  
Создан для организаторов конкурсов, которые хотят прозрачно и быстро подвести итоги голосования в соцсетях (например, ВКонтакте).

---

## 📦 Требования

- **Node.js** версии 14 или выше — [скачать](https://nodejs.org/)
- Базовое умение работать с командной строкой (терминалом)
- Любой текстовый редактор (Блокнот, VS Code, Notepad++)

---

## 🚀 Быстрый старт

1. **Скачайте все файлы скриптов** в одну папку:
    - `pipeline.js`
    - `parseVotes.js`
    - `extractPairs.js`
    - `extractUniquePairs.js`
    - `countVotesWithSynonyms.js`
    - `generateReport.js`
    - `pairNormalizer.js`
2. **Создайте две папки** внутри:
    - `input` – сюда положите JSON-файлы с комментариями
    - `output` – сюда будут сохраняться результаты (создастся автоматически)
3. **Запустите пайплайн**:

    ```bash
    node pipeline.js
    ```

> Пайплайн будет останавливаться, когда потребуется ваше ручное вмешательство, и подскажет, что делать.

---

## 📂 Формат входных данных (JSON)

Каждый файл в папке `input` должен быть назван по номинации, например `Лучшая пара.json`.  
Содержимое – массив объектов с такими полями:

```json
[
  {
    "userId": "123456789",
    "username": "Анна Иванова",
    "text": "Голосую за пару Иван Петров - Мария Сидорова!",
    "timestamp": "2025-03-15T14:30:00",
    "isReply": false,
    "parentId": null
  }
]
```

| Поле      | Тип          | Описание                                                |
|-----------|--------------|---------------------------------------------------------|
| userId    | строка/число | Уникальный идентификатор пользователя                   |
| username  | строка       | Имя пользователя (для отчёта)                           |
| text      | строка       | Текст комментария                                       |
| timestamp | строка       | Дата и время в ISO-формате                              |
| isReply   | boolean      | Является ли комментарий ответом                         |
| parentId  | строка/число | ID родительского комментария (если isReply = true)      |

## ⚙️ Этапы работы (что происходит под капотом)

1. **`parseVotes.js` – разбор комментариев**
   - Удаляются эмодзи.
   - Комментарий распознаётся как голос, если содержит ключевые слова (например, «голосую», «выдвигаю», «номинирую», «отдаю голос» …)
   - Дополнения (короткие сообщения, ссылки) выделяются отдельно.
   - Результаты сохраняются в `output/Номинация/`:
     - `votes.json` – все голоса
     - `additions.json` – дополнения
     - `other.json` – прочие комментарии

2. **`extractPairs.js` – извлечение пар**
   - Автоматически находит в тексте пары вида «Имя Фамилия – Имя Фамилия».
   - Поддерживаются тире, «и», «с», «&», «/», VK-теги `[id123|Имя Фамилия]`, короткие варианты.
   
   **❗ Если есть нераспознанные комментарии**
   - Появится файл `votes_unrecognized.json`.
   - В консоли будет инструкция:
   
   ```
   💡 Совет: скопируйте votes.json в votes_with_manual.json, найдите нераспознанные записи...
   ```

   **Что делать:**

   1. Скопируйте votes.json → votes_with_manual.json.
   2. Откройте votes_with_manual.json.
   3. Для каждого нераспознанного комментария добавьте поле `"withManual"`:
      - `"cleanedText"` – если вручную исправляете text для корректного извлечения пар.
      - `"notPairs"` (или `"noPairs"`) – если в комментарии нет пар, он будет проигнорирован.
   4. Сохраните файл и снова запустите пайплайн.

   **Пример:**
   ```json
   {
     "userId": "123",
     "username": "Анна",
     "text": "Очень нравится Иванов Петр - Сидорова Мария!",
     "cleanedText": "Иванов Петр - Сидорова Мария",
     "withManual": "cleanedText"
   }
   ```

   > ⚠️ Не изменяйте поля `userId`, `username`, `timestamp`, `text` — скрипт проверяет их на целостность!

3. **`extractUniquePairs.js` – нормализация и уникальные пары**
   - Строится карта фамилий для канонизации.
   - Пары приводятся к виду «Имя Фамилия - Имя Фамилия» с сортировкой по фамилии.
   - Создаётся файл `unique_pairs.json` со списком всех уникальных пар.

4. **Ручное создание `synonyms.json` (объединение вариантов)**
   - Если одну и ту же пару пишут по-разному — их объединяем вручную:
   1. Откройте unique_pairs.json.
   2. Создайте в папке файл `synonyms.json` такого вида:
      ```json
      [
        {
          "canonical": "Иван Петров - Анна Смирнова",
          "variants": [
            "Петров Иван - Смирнова Анна",
            "Иван Петров – Анна Смирнова"
          ]
        },
        {
          "canonical": "Мария Сидорова - Ольга Кузнецова",
          "variants": [
            "Сидорова Мария - Кузнецова Ольга"
          ]
        }
      ]
      ```
   - canonical – основной вариант для отчётов.
   - variants – массив альтернативных написаний (точь-в-точь, как в unique_pairs.json).
   
   > Если какая-то пара не была учтена — на следующем этапе появится файл `uncovered_variants.json` со списком недостающих.

5. **`countVotesWithSynonyms.js` – подсчёт голосов**
   - Каждая пара приводится к каноническому виду через `synonyms.json`.
   - Голоса группируются по пользователям (учитывается не более 3 голосов от одного пользователя, по времени).
   - Результаты сохраняются в `votes_results.json`:

   ```json
   {
     "nomination": "Лучшая пара",
     "total_unique_voters": 45,
     "total_votes_submitted": 67,
     "total_votes_counted": 45,
     "total_votes_uncounted": 22,
     "pairs": [
       {
         "pair": "Иван Петров - Анна Смирнова",
         "total_votes": 12,
         "votes": [ /* ... */ ],
         "uncounted_votes": [ /* ... */ ]
       }
     ]
   }
   ```

6. **`generateReport.js` – публичный отчёт**
   - Создаёт user-friendly файл `public_report.json` (без данных пользователей):

   ```json
   {
     "nomination": "Лучшая пара",
     "total_voters": 45,
     "pairs": [
       { "place": 1, "pair": "Иван Петров - Анна Смирнова", "votes": 12 },
       { "place": 2, "pair": "Мария Сидорова - Ольга Кузнецова", "votes": 9 }
     ]
   }
   ```
   - В консоль выводится топ-5 пар.

## 🧭 Порядок запуска: шпаргалка

1. Положите корректно оформленные JSON-файлы в `input/`.
2. Откройте терминал в папке со скриптами.
3. Выполните:
    ```bash
    node pipeline.js
    ```
4. Следуйте инструкциям.  
   Если просит файл `votes_with_manual.json` — создайте, исправьте и перезапустите.
   Если просит файл `synonyms.json` — создайте, заполните и перезапустите.
5. Дождитесь сообщения `🎉 Пайплайн успешно завершён!`
6. Извлеките результаты:

- `output/Номинация/votes_results.json` — все данные;
- `output/Номинация/public_report.json` — отчёт для публикации.

## ❓ Частые проблемы и решения

| Сообщение об ошибке               | Что делать                                                                                 |
|-----------------------------------|--------------------------------------------------------------------------------------------|
| Нет номинаций в папке output      | Запустите pipeline.js (он создаст папку, если есть файлы в input)                          |
| Ошибка на этапе parseVotes        | Проверьте, что JSON-файлы в input — валидные массивы с нужными полями                      |
| Изменены защищённые поля          | В votes_with_manual.json были изменены userId/username/timestamp/text — их нельзя менять   |
| Вариант X не найден в synonyms    | Скрипт создал uncovered_variants.json — добавьте недостающие пары в synonyms.json          |
| Скрипт не видит изменения в synonyms.json | Просто сохраните файл и перезапустите node pipeline.js                           |

---

## 🔄 Как перезапустить всё с начала

Удалите файл `.pipeline_state.json` (и, при необходимости, папку output).  
Снова выполните `node pipeline.js`.
